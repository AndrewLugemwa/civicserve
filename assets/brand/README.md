# Brand assets

`council-mark.svg` is a neutral placeholder mark designed for CivicServe. It is not the emblem of any council or
government.

To use a council's own logo once it has authorised it:

1. Save it here, e.g. `assets/brand/council-logo.svg` (SVG preferred; otherwise a square PNG of at least 256×256 px).
2. In `includes/config.php`, set `'logo' => 'assets/brand/council-logo.svg'`.
3. Hard-refresh the browser.

Do not add national insignia (such as a coat of arms) without written authorisation.
